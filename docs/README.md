# OpenEphys.EphysVisualization

OpenEphys.EphysVisualization is a [Bonsai](https://bonsai-rx.org/) library of visualization tools for electrophysiology, maintained by [Open Ephys](https://open-ephys.org/). It covers both the display of recorded signals and the interfaces used to configure acquisition instruments.

The documentation is at [open-ephys.github.io/bonsai-ephysvisualization](https://open-ephys.github.io/bonsai-ephysvisualization/).

The library is released under the [MIT License](https://github.com/open-ephys/bonsai-ephysvisualization/blob/main/LICENSE).
